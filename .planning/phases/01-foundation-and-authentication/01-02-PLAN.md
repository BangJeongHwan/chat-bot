    **TokenService.kt** (`com.stockbot.auth.service`):
    - `@Service` class injecting `@Value("\${jwt.secret}") secret: String` and `RefreshTokenRepository`
    - `private val key: SecretKey` initialized from `Jwts.SIG.HS256.key().build()` or from `Keys.hmacShaKeyFor(secret.toByteArray())` — use jjwt 0.13.0 API
    - `fun createAccessToken(userId: String, email: String, isVerified: Boolean): String` — builds JWT with subject=userId, claims `email` and `is_verified`, issuedAt=now, expiration=now+15min. Uses `Jwts.builder().subject(userId).claim("email", email).claim("is_verified", isVerified).issuedAt(Date()).expiration(Date(System.currentTimeMillis() + 15 * 60 * 1000)).signWith(key).compact()`
    - `fun validateAccessToken(token: String): Claims` — parses and validates JWT. Returns claims. Throws on invalid/expired.
    - `fun issueTokenPair(userId: String, email: String, isVerified: Boolean): TokenPair` — creates access token + generates random UUID for refresh token, SHA-256 hashes the refresh token, saves `RefreshToken` entity with hash and expiresAt=now+7days, returns `TokenPair(accessToken, rawRefreshToken)`
    - `fun rotateRefreshToken(rawToken: String): Pair<TokenPair, String>` — SHA-256 hashes the input, looks up by hash. If not found, throw `RefreshTokenInvalidException`. If found but expired, delete it and throw `RefreshTokenExpiredException`. Delete ALL tokens for that userId (rotation per D-04). Issue new token pair. Return `Pair(tokenPair, storedToken.userId)`.
    - Private `fun sha256(input: String): String` using `MessageDigest.getInstance("SHA-256")` returning hex string.

    **AccountService.kt** (`com.stockbot.account.service`):
    - `@Service` class injecting `AccountRepository`
    - `fun createDefaultAccount(userId: String): Account` — creates Account with `name = "기본 계좌"`, `balanceKrw = BigDecimal("100000000")`, `balanceUsd = BigDecimal.ZERO`, `initialBalance = BigDecimal("100000000")`, `isDefault = true`. Per D-10, this is called atomically within registration.
    - `fun getAccountsByUserId(userId: String): List<Account>` — returns all accounts for user.

    **AuthService.kt** (`com.stockbot.auth.service`):
    - `@Service` class injecting `UserRepository`, `AccountService`, `TokenService`, `PasswordEncoder`
    - `@Transactional fun register(request: RegisterRequest): Pair<AuthResponse, String>` — check `userRepository.existsByEmail`, if true throw `EmailAlreadyExistsException`. Create `User(email=request.email, passwordHash=passwordEncoder.encode(request.password))`. Save user. Call `accountService.createDefaultAccount(user.id)`. Call `tokenService.issueTokenPair(user.id, user.email, false)`. Return `Pair(AuthResponse(accessToken, UserResponse from user), rawRefreshToken)`. Per D-01: isVerified starts as false, login is allowed immediately.
    - `fun login(request: LoginRequest): Pair<AuthResponse, String>` — find user by email, if null throw `InvalidCredentialsException`. Check `passwordEncoder.matches(request.password, user.passwordHash)`, if false throw `InvalidCredentialsException`. Issue token pair. Return response.
    - `fun refresh(rawRefreshToken: String): Pair<AuthResponse, String>` — call `tokenService.rotateRefreshToken(rawRefreshToken)`. Load user by userId from the returned pair. Return new AuthResponse + new rawRefreshToken.
    - `@Transactional fun logout(rawRefreshToken: String)` — hash token, delete by hash from refresh_tokens table.

    **AuthController.kt** (`com.stockbot.auth.controller`):
    - `@RestController @RequestMapping("/api/v1/auth")`
    - `@PostMapping("/register") fun register(@Valid @RequestBody request: RegisterRequest): ResponseEntity<AuthResponse>` — calls authService.register, sets refresh token cookie via `addRefreshTokenCookie(response, rawRefreshToken)`, returns 201 with AuthResponse body.
    - `@PostMapping("/login") fun login(@Valid @RequestBody request: LoginRequest): ResponseEntity<AuthResponse>` — same pattern, returns 200.
    - `@PostMapping("/refresh") fun refresh(@CookieValue("refresh_token") refreshToken: String): ResponseEntity<AuthResponse>` — calls authService.refresh, sets new cookie, returns 200.
    - `@PostMapping("/logout") fun logout(@CookieValue("refresh_token", required = false) refreshToken: String?): ResponseEntity<Void>` — if token present, calls authService.logout. Clears cookie. Returns 204.
    - Private `fun addRefreshTokenCookie(response: HttpServletResponse, rawToken: String)` — creates `ResponseCookie.from("refresh_token", rawToken).httpOnly(true).secure(true).sameSite("Strict").path("/api/v1/auth").maxAge(Duration.ofDays(7)).build()`. Adds via `response.addHeader("Set-Cookie", cookie.toString())`. Per D-03: refresh token in httpOnly cookie only.
